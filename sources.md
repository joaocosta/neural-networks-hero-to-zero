# Source repositories

Use a stable ID from this registry in lecture frontmatter. Keep `workspace/` disposable: push meaningful experimental commits to your personal fork.

## Entry format

### `source-id`

- **Purpose:** What this repository supports
- **Upstream:** https://github.com/owner/project
- **Fork:** https://github.com/your-user/project
- **Workspace:** `workspace/project`
- **Branch:** `study-branch`
- **Tested commit:** `full-commit-sha`
